Metadata review

Suggestions are extracted from retained source pages. Decisions are reviewed and recorded; no source metadata is silently rewritten.

To correct an author name with stray symbols, match the intended existing person or create a person with the cleaned canonical name, then approve. The parsed name stays as evidence and becomes a reviewed alias; the catalogue displays the canonical name. This does not train or change the parser.

Reject means “do not apply this suggestion”, not “remove this author from the catalogue”. Rejected suggestions are not proposed again automatically. You can reopen one with a reason to return it to Pending; this preserves decision history and applies no metadata. Approved facts cannot be undone here.

Browse correction history

Review defaults to German, English and French. Unknown-language evidence is hidden unless you choose All languages. Author suggestions may combine evidence from several languages; filtering uses the primary capture, not the person's nationality.
