Book outline

Section workflow help

Branch lines trace the book, sections and headings. Right-click a section or heading (Shift+F10 by keyboard) for title/URL/role, move, add or boundary repair. Drag a section title onto another section's row: upper third = before, middle third = inside, lower third = after. A line marks before/after; an inset outline marks inside. Move section offers the same placements without dragging. The left control column stacks +/− for outline branches, the triangle for editor content, and … for actions. Click a title to scroll; Show focuses one part.

Whole book. Saving always includes all parts.

Complete metadata

Right-click a row, or press Shift+F10 in a field, to add or remove fields, link registered authors, or show/hide a field in the title-page preview (Shift+right-click keeps the browser menu). Italic labels are not shown on the Title page. Empty rows are ignored.
Book Without an explicit Type, a book gets a full title page and a contents page; an article gets a compact title and no contents page. Right-click Title, ToC or Metadata in the navigation to override.

About these fields

Changes belong to this corrected document, not the original source or catalogue. Author is derived from the author rows; names are scoped to this document and never merge catalogue identities. Excluded attributions are kept in metadata but not displayed.

Dates use the precision known from the source (YYYY, YYYY-MM or YYYY-MM-DD); an end date makes a range of matching precision in chronological order. Only one publication date is supported. Once any date is edited, all date rows are stored as typed values without copying parser evidence as new certification; the pinned starting version keeps the original evidence.

Book classification is independent of the number of sections; retained source-page count is unchanged.

Fill empty fields from editorial note reads the first content paragraph made of “Label: value” lines (as on marxists.org: Written, Source, Translated, Transcription/Markup…). It only fills empty fields, never changes content, and unrecognised labels go to Other notes. Review the result before saving.

The Title page shows a live preview of the filled fields chosen for it. Right-click the preview or a row here to show or hide a field; the choice is saved with the document and used by the reader, publication and PDF.

Linking a person to a registered author uses the shared author registry; registering a new author adds it to that registry immediately, while the link itself saves with this document.

    Section title, URL and role

    The selected heading is labeled in the canvas. Changing URL records a citation only; it does not fetch or replace content. Targets, links and all other sections are preserved. One undo step; save and publish separately.

    Remove section

    Other content's links and excerpt origins must remain valid. Deletion is refused when it would break them. Nothing changes in the retained source or catalogue; a removed page is not automatically made a separate work. One Undo step; save and publish separately.

    Separate whole blocks as an excerpt section

    
    
    The complete selected blocks become a titled child section at their current position, without copying or changing their text, formatting, targets, links or images. Any combination of sibling blocks is supported, including headings, lists, tables, figures, quotations, preformatted text and rules. Ctrl/Cmd-click toggles whole blocks; selected blocks must be contiguous within one section. Partial blocks and gaps are refused. Move the new section independently using the outline. Its original parent section and source URL remain attached after movement. This edits the current document, not a raw-source excerpt definition. One Undo step; save and publish separately.
