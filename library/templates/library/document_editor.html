About these fields

Changes belong to this corrected document, not the original source or catalogue. Author is derived from the author rows; names are scoped to this document and never merge catalogue identities. Excluded attributions are kept in metadata but not displayed.

Dates use the precision known from the source (YYYY, YYYY-MM or YYYY-MM-DD); an end date makes a range of matching precision in chronological order. Only one publication date is supported. Once any date is edited, all date rows are stored as typed values without copying parser evidence as new certification; the pinned starting version keeps the original evidence.

Book classification is independent of the number of sections; retained source-page count is unchanged.

Fill empty fields from editorial note reads the first content paragraph made of “Label: value” lines (as on marxists.org: Written, Source, Translated, Transcription/Markup…). It only fills empty fields, never changes content, and unrecognised labels go to Other notes. Review the result before saving.

The Title page shows a live preview of the filled fields chosen for it. Right-click the preview or a row here to show or hide a field; the choice is saved with the document and used by the reader, publication and PDF.

Linking a person to a registered author uses the shared author registry; registering a new author adds it to that registry immediately, while the link itself saves with this document.

    Editing help and keyboard shortcuts

    Ctrl/Cmd-click toggles whole-block selection within a section. Right-click or Shift+F10 opens selection and section tools; selected blocks must be contiguous to become an excerpt section. Click within a list, table or figure to select that whole block.

    Enter splits paragraphs and Backspace joins them. Ctrl/Cmd+C and Ctrl/Cmd+V copy semantic content, preserving formatting, links and retained images; external paste opens a preview. Ctrl/Cmd+Z and outline Undo restore edits.

    Bulleted list and Numbered list act on a paragraph or complete sibling items; click the active type to remove list formatting. New plain items contain text directly, without paragraph wrappers; paragraphs with IDs or styling are retained. Selection tools includes Indent item, Outdent item and Move item up/down. Enter splits an item; Shift+Enter adds a line break. Enter removes an empty interior item or exits a final empty item one level, preserving targets and styling. Backspace at an item's start or Delete at its end joins compatible siblings. Unsafe target/style loss, internal structural joins and numbering resets are refused without changing content. Tab moves focus normally.

    HR / Insert horizontal rule adds a rule at an ordinary paragraph caret, outside lists, figures, tables and notes. Text after the caret stays in a following paragraph. Undo restores the original. List labels and vertical bars belong to UL/OL containers, not LI items. These and HR cues are editor-only; they do not appear in Read or PDF.

    Use paragraph up/down for adjacent blocks in the same container; use the outline to reorder sections. Blocks cannot move across sections, lists, tables or media. Shift+right-click keeps the browser menu. The outline and toolbar stay in normal page flow; the desktop content canvas scrolls independently.
