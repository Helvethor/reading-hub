Worker administration

Controls are available to signed-in administrators. Default: one worker with a 1024 MiB (1 GiB) memory ceiling. Workers handle imports first, then enabled crawls and archive sampling. Different sources and sampling can run concurrently. Each source and the sampling run have one processing slot; source request intervals are shared.

Stop and restart finish the current task first. A stopped worker stays stopped. Crashed workers are not automatically restarted. Running workers continue if this page is closed or the web server is restarted. Changes to memory ceilings require a restart.

The OS ceiling limits virtual address space, not exact physical RAM; it does not reserve memory. Current RAM usage below is resident memory (RSS). Exceeding the ceiling fails the job and stops that worker; increase its ceiling before retrying. The configured total ceiling is not a guarantee against system-wide memory pressure.
